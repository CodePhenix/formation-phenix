## Documentation 2 (en anglais)
The `<input>` HTML element is used to create interactive controls for web-based forms in order to accept data from the user.

The `type` attribute defines the kind of data the input expects, such as text, password, email, or number.

Inputs can also include attributes like `placeholder` (the short text displayed in a form to guide the user when the input has no value), 

`required` (the user must specify a value for the input before the form can be submitted), and `value` (it corresponds to the initial value set in HTML).

The `<input>` element is usually used inside a `<form>` element, but it can also be used independently outside a form. See the example below :

```html
<form>
  <label for="email">Email:</label>
  <input type="email" id="email" placeholder="Enter your email" required>

  <label for="age">Age:</label>
  <input type="number" id="age" min="1" max="120">

  <button type="submit">Submit</button>
</form>
```
