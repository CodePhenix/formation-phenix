## Objectif

Lors de la certification, l'épreuve d'anglais va demander la lecture d'une documentation en anglais, qu'il va falloir comprendre, puis répondre à plusieurs questions :
- des questions fermées à choix unique en français,
- des questions ouvertes en anglais, auxquelles il va falloir répondre en anglais.

## Instructions

- Lire la documentation en anglais calmement, d'un seul coup une première fois.
- Prendre le temps de repérer les mots compris.
- Déduire le sens global de la phrase, même si tous les mots ne sont pas compris.
- Faire attention à la négation qui change le sens de la phrase (présence de mots comme `no`, `not` ou `don't`/`doesn't`).
- Lire les questions en français, puis celles en anglais, en essayant de bien comprendre ce que demandent les questions.
- Repérer dans la documentation les phrases qui pourraient répondre aux questions posées.
- Répondre aux questions.

## Documentation 1 (en anglais)
Adding the flex-direction property to the flex container allows us to change the direction in which our flex items display. Setting flex-direction: row-reverse will keep the items displaying along the row, however the start and end lines are switched.

If we change flex-direction to column the main axis switches and our items now display in a column. Set column-reverse and the start and end lines are again switched.

The live sample below has flex-direction set to row-reverse. Try the other values — row, column and column-reverse — to see what happens to the content.

## 1ere étape : Questions fermées (choix unique) en français
### 1. Que fait flex-direction: column ?
- [ ] A. Affiche les éléments en ligne horizontale
- [ ] B. Affiche les éléments en colonne verticale
- [ ] C. Cache les éléments

### 2. Que change flex-direction: row-reverse ?
- [ ] A. Il transforme l’affichage en colonne
- [ ] B. Il supprime les éléments
- [ ] C. Il inverse le sens de la ligne (start et end sont inversés)
- [ ] D. Il empêche le flexbox de fonctionner

## 2eme étape : Open questions (short answers) in english
### 3. What CSS property is used to change the direction of flex items?

### 4. What happens when flex-direction: column-reverse is used?

#### Aide bonus pour questions 3 et 4
- What : quel (ou quelle)
- CSS property : propriété CSS (en anglais, l'ordre des adjectifs est inversé)
- use : utiliser / is used : être utilisé
- to change : pour changer
- What happens : que se passe-t-il ?
- when : quand
