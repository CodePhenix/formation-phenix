## Documentation 5 (en anglais)
The querySelector() method returns the first element within the document that matches a specified CSS selector.

If no matching element is found, it returns null.

The querySelectorAll() method returns a static NodeList representing a list of elements that match the specified group of selectors.

Unlike querySelector(), it can return multiple elements.

The NodeList returned by querySelectorAll() is static and not live, meaning it does not automatically update when the DOM changes.

Both methods allow developers to select elements using CSS selector syntax such as class, id, or tag names.

These methods are widely used in modern JavaScript for DOM manipulation.
