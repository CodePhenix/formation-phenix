## Documentation 4 (en anglais)
The aria-label attribute defines a string value that labels an element.

It is used to provide an accessible name when an element does not have visible text that can be used as a label.

Screen readers use the value of aria-label to announce the purpose of the element to users.

This attribute is useful for icon buttons or controls that do not contain text.

However, aria-label should only be used when no visible label is available, because visible text is always preferred for accessibility.

Overusing aria-label can make maintenance harder and reduce clarity in the user interface.

```HTML
<button aria-label="Close">✖</button>

<button aria-label="Search">🔍</button>
```
