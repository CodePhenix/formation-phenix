## Objectif

Vous allez simuler l'avancée d'un projet web, dans un cadre professionnel.

Vous disposez de votre terminal où effectuer des commandes, ainsi que de l'interface de Github/Gitlab.

Vous allez récupérer le "faux" projet initial et son contenu via Github/Gitlab en clonant le dépôt, puis laissez-vous guider par les niveaux pour progresser et apprendre les commandes Git et les bonnes pratiques de travail.
